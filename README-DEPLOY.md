# 🎮 Combat Chat — دليل النشر على استضافة خارجية

ده مشروع **شات الغرف** بتاع لعبة Combat Online 2 — سيرفر واحد موحّد (`server.js`) بيشغّل:
- موقع Next.js (الواجهة الذهبية)
- خدمة الشات Socket.io (الغرف + الرسايل + مضاد السبام)

على **نفس البورت** — يعني رفع واحد على أي منصة = لينك واحد شغال بالكامل.

> ⚠️ **ملاحظة مهمة:** الغرف والرسايل في الذاكرة (عمداً). آخر واحد يسيب الغرفة بيمسح كل حاجة،
> وريستارت السيرفر بيمسح الغرف. ده نفس السلوك المُختبَر — مناسب لـ 30 لاعب بالكتير.

---

## أ) Railway (الأسهل — من غير كارت)

1. ادخل [railway.app](https://railway.app) وسجّل بحساب GitHub (إصدار تجريبي بـ $5 مجاناً).
2. **New Project → Deploy from local** أو ارفع المجلد ده على GitHub واعمل **New Project → Deploy from GitHub repo**.
3. Railway هيقرأ `railway.json` تلقائياً ويبني ويشغّل — من غير أي إعدادات.
4. بعد ما يخلص: **Settings → Networking → Generate Domain** → هيديك لينك دائم `https://combat-chat-xxx.up.railway.app`.

**بدائل سطر الأوامر (لو حابب أنا أنفذها ليك):** اعمل حساب، وبعدين من صفحة Account Tokens اعمل Token وابعتهولي في الشات — أنا هنفّذ النشر كامل من عندي وأرجعلك باللينك.

## ب) Render.com (مجاني 100% — بس بينام)

1. ارفع المجلد على GitHub.
2. [render.com](https://render.com) → **New → Web Service** → اختار الريبو.
3. Render هيقرأ `render.yaml` تلقائياً (Build: npm install + build، Start: npm start).
4. اللينك: `https://combat-chat.onrender.com`.

> ⚠️ الخطة المجانية بتوقف التطبيق بعد 15 دقيقة من غير زوار، وأول زائر بعدها بيستنى ~50 ثانية للإقلاع. الغرف بتتمسح مع كل إيقاف.

## ج) Hugging Face Spaces (مجاني، من غير كارت، مش بينام بسرعة)

1. اعمل حساب مجاني على [huggingface.co](https://huggingface.co).
2. **New Space** → SDK: **Docker** → ارفع محتويات المجلد ده.
3. بدّل اسم ملف `hf-space-README.md` لـ `README.md` (فيه إعدادات الـ Space جوّاه).
4. اللينك: `https://اسمك-combat-chat.hf.space` — شغال 24/7 (بينام بعد 48 ساعة من غير زوار وبيصحى بأول زيارة).

## د) Fly.io (قوي وثابت — محتاج كارت للتوثيق)

```bash
# بعد تثبيت flyctl
fly launch --no-deploy     # هيقرأ fly.toml
fly deploy
fly status                 # اللينك: https://combat-chat.fly.dev
```

## هـ) VPS بتاعك (Oracle Cloud Free / أي سيرفر)

```bash
# على السيرفر (Ubuntu)
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash - && sudo apt install -y nodejs
# انقل المجلد للمسار /opt/combat-chat
cd /opt/combat-chat
npm install --no-audit --no-fund --legacy-peer-deps
npm run build
sudo PORT=80 npm start      # أو استخدم pm2:
sudo npm i -g pm2 && pm2 start server.js --name combat-chat -- --time && pm2 save && pm2 startup
```

## و) Docker في أي مكان

```bash
docker build -t combat-chat .
docker run -p 80:3000 -e PORT=3000 combat-chat
```

## بعد النشر — اختبار سريع (30 ثانية)

1. افتح `https/<لينكك>/healthz` → لازم يرد `{"ok":true,...}`.
2. افتح اللينك → اعمل غرفة → انسخ **رابط الدعوة** وابعته لصاحبك.
3. صاحبك يفتح اللينك → يدخل الكود (أو اللينك مباشرة) → رسالة أول 5 ثواني بتوصل فوراً = الاتصال شغال.

## ملاحظات تشغيل

| النقطة | التفصيل |
|---|---|
| **زمن الاستجابة من مصر** | اختار منطقة أوروبا الغربية (Paris/Frankfurt/London) = 40-70ms |
| **حد الغرفة** | 30 لاعب، 300 غرفة، 500 رسالة محفوظة |
| **مضاد السبام** | 8 رسايل/10 ثواني = كتم 15 ثانية، تكرار خلال 5 ثواني = رفض |
| **فترة السماح** | قفل التاب وفتحه تاني خلال 60 ثانية = بيرجع لمكانه بصمت |
| **الاسم المقفول** | محفوظ في جهاز اللاعب (`localStorage`) — بيتبع الجهاز مش السيرفر |
| **SSL** | كل المنصات دي بتدي HTTPS مجاناً تلقائي |

## المتغيرات البيئية

| المتغير | مطلوب؟ | الافتراضي | الوصف |
|---|---|---|---|
| `PORT` | لا | `3000` | المنصات بتحدده تلقائياً |
| `HOST` | لا | `0.0.0.0` | سيبه زي ما هو |
| `NODE_ENV` | لا | `production` في `npm start` | سيبه |

مفيش قواعد بيانات ومفيش مفاتيح API — كل حاجة جاهزة من غير إعدادات.
